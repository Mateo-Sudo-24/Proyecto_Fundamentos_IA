# 🧠 Modelo Predictivo de Actividad Lícita con Flask + Machine Learning

Este proyecto permite predecir actividades financieras lícitas o sospechosas utilizando un modelo de regresión logística entrenado con scikit-learn. Se integra con Flask para exponer una interfaz web.

## 🚀 Tecnologías

- Flask
- scikit-learn
- joblib
- HTML + CSS
- Gunicorn (para despliegue)
- Render.com / Heroku

## 📦 Instalación

```bash
git clone https://github.com/tuusuario/modelo-predictivo.git
cd modelo-predictivo
pip install -r requirements.txt
python src/app.py
